# Pre-commit Hooks Guide

## How It Works

Every time you run `git commit`, the following checks will automatically run:
1. **Trailing whitespace** - Removes trailing spaces
2. **End of file fixer** - Ensures files end with a newline
3. **YAML/JSON/TOML validators** - Checks file syntax
4. **Ruff** - Fast Python linter (replaces flake8, isort, pyupgrade)
5. **Ruff-format** - Fast Python formatter (replaces Black)

## Installation

```bash
# Install the package with development dependencies
pip install -e ".[dev]"

# Install the git hooks (one-time setup)
pre-commit install
```

## Usage

### Automatic (on commit)
```bash
git add your_file.py
git commit -m "Your message"
# Pre-commit hooks run automatically
```

### Manual run on all files
```bash
pre-commit run --all-files
```

### Manual run on staged files only
```bash
pre-commit run
```

### Skip hooks (use sparingly!)
```bash
git commit --no-verify -m "Your message"
```

### Update hooks to latest versions
```bash
pre-commit autoupdate
```

## Configuration

The configuration is in `.pre-commit-config.yaml`.

### Current Setup (Ruff-based)

We use **Ruff** - a fast, modern Python linter and formatter written in Rust that replaces multiple tools like flake8, isort, pyupgrade, black:

### Ruff Configuration

Configured in `pyproject.toml`:
- **Line length**: 120 characters
- **Target Python**: 3.9+
- **Auto-fix**: Enabled (tries to fix issues automatically)
- **Rule sets enabled**:
  - E/W (pycodestyle errors and warnings)
  - F (pyflakes)
  - I (import sorting)
  - UP (syntax upgrades)
  - B (bugbear - find likely bugs)
  - C4 (comprehensions)
- **Notebooks**: Excluded some errors in linting (`.ipynb` files)

### Ignored Rules

Some rules are intentionally ignored:
- `B006` - Mutable defaults
- `B008` - Function calls in defaults
- `C408` - dict() vs {}
- `UP031` - % formatting

You can adjust these in `pyproject.toml` under `[tool.ruff.lint]`.

### First run is slow

The first time pre-commit runs, it downloads and caches all tool environments. This is a one-time setup and takes a few minutes. Subsequent runs are very fast.
